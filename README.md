## 🔭 Personal project

### 🏦 wealth.ai

A personal project exploring how public European financial data can be turned into a practical banking decision-support system in two layers:

**`tfm-project` · Data Foundation & Analysis** -> Analysis of household finances in Malta using public **Eurosystem Household Finance and Consumption Survey (HFCS)** data.

**`banking-products-recommender` · Decision System & Application** -> A banking-product recommendation system to evaluate suitable **saving, investment and financing product types**.

The longer-term goal is a user-facing application where people can understand their financial position relative to Malta and euro-area benchmarks, simulate savings or borrowing scenarios, and receive explainable product recommendations.

> **Data → financial context → decision logic → recommendation → application**
